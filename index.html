Situation A: defer

script ที่ต้องรอให้ HTML ทั้งหน้า parse เสร็จก่อน และต้องรันตามลำดับกับ script อื่น (เช่น ต้องพึ่งพา DOM element ที่อยู่ท้ายหน้า)

Situation B: async

script วิเคราะห์ (analytics) ที่ไม่สนใจ DOM เลย และไม่แคร์ลำดับการรันกับ script อื่น อยากให้โหลดเร็วที่สุด

Situation C: ไม่ต้องใส่อะไรเลย

script เล็กๆ ที่วางไว้ท้ายสุดของ 'body' อยู่แล้ว (หลัง content ทั้งหมด)
